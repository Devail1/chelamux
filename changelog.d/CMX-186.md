### Added

- **Spike: Telegram plain text through Claude Code's `--channels`. Verdict: NO-GO.**
  `docs/TELEGRAM_CHANNELS_SPIKE.md` compares channel delivery with the tmux paste path on
  isolated sessions. Channels were faster and never stranded a message, but Claude Code
  classifies channel input as external. An operator's instruction that arrived while the
  agent was busy was refused 3 times out of 3, and an unregistered channel drops messages
  silently. The prototype lives in `scripts/spikes/telegram_channels/`. The Telegram bridge
  is unchanged. (CMX-186)
