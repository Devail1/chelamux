### Added

- **Every judge and self-check suite run now has its own memory ceiling.** chela wraps each
  run in its own `systemd-run --user --scope` (`CHELA_SUITE_MEMORY_MAX`, default 5.1G, which
  is 3x the measured 1.69 GiB peak of a full suite run; `0` turns it off). A run that blows
  through its ceiling is killed inside its scope and reported as CANNOT VERIFY ("suite
  exceeded 5.1G"), never as a pass. chela claims the ceiling only when the suite's own
  `/proc/self/cgroup` names the scope. Whatever a suite leaks into its scope, such as a
  daemon that ignores SIGTERM, is SIGKILLed when the run ends. (CMX-119)
