### Added

- **Pending approvals on the dashboard — no Telegram needed.** While an override request
  waits, a **⚖️ N pending approvals** pill shows on every page (live over SSE). It lists what
  is asked (`override-merge CMX-N past <verdict> on <sha>`), who asked, the reason, age and
  time to expiry. **Approve…** needs a second tap and goes through the same decide path as
  `/override/<id>` (re-checking head, CI and MERGEABLE); a request chela knows cannot merge
  says why instead of offering Approve. Decisions are recorded as `decided_by: "dashboard"`.
  A share guest sees no controls. Settings → Notifications adds an opt-in browser
  notification for new requests (off by default). `chela merge --override` now prints the
  absolute dashboard link (`CHELA_DASHBOARD_URL`, else the bound address) and
  `chela merge-approve`. The merge-gate hook (plugin 0.2.9) also denies a Claude session's
  request to `/api/approvals/`. Release requests (CMX-87) plug into `chela/approvals.py`'s
  `KINDS`. (CMX-103)
