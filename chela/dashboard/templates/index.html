A board for work in flight
The Kanban board tracks dispatched work across all your WORKFLOW.md files — open tasks, agents running now, PRs awaiting review, and done — in one place. It fills in once the dispatcher has workflows to watch.
Enable it: set CHELA_DISPATCH_WORKFLOWS to a colon-separated list of WORKFLOW.md paths, then restart the daemon.
⇶
Turn a TODO list into pull requests
Point chela at a WORKFLOW.md — a plain markdown checklist. For every open - [ ] item it spins up a git worktree, launches a Claude agent in a fresh tmux window with that task as its prompt, and opens a PR when the agent finishes. Merge the PR and the line checks itself off on the next tick. This is what makes chela an orchestrator, not just a viewer.
Use + Init a repo above to seed the files, then set CHELA_DISPATCH_WORKFLOWS to a colon-separated list of WORKFLOW.md paths and restart the daemon.

Put an agent on a schedule
A schedule pokes an agent on a recurring cadence — every 30m, a cron expression, or once at a set time. When it fires, chela types your prompt into that agent's tmux window. Use it to let a researcher refresh itself hourly, or run a risk check every 20 minutes — no human in the loop.
