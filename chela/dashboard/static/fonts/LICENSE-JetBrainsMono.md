# JetBrains Mono — license & attribution

`JetBrainsMono.ttf` in this directory is bundled as the Latin/monospace body font
for the web terminal, so English text renders in a real monospace on any viewer
regardless of what fonts are installed locally (see the note in `app.py`
`_TERM_FONT_CSS` on why this must be bundled, not left to device fonts). It is a
variable font (weight axis 100–900).
