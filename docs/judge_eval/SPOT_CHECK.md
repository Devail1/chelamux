# Judge-eval label spot-check (operator)

`chela judge eval label` labelled every historical judge finding **real** or **contrived**
with the rubric (`chela/judge_eval/rubric.md`). This sheet is a random 20% of those labels
(seed 408), drawn from **train cases only**, so reviewing it never shows you a test-set
answer.

**How to fill it in:** for each row, read the diff and write `real` or `contrived` in the
**operator** column, using the rubric's test: *could a plausible future edit produce this
breakage?* Add a note wherever you disagree. Then run `chela judge eval agreement`, which
prints the agreement rate and the rows where you disagreed. Copy that result into
`docs/JUDGE_EVAL.md` → *Label agreement*.

Regenerate the sheet with `chela judge eval spot-check`. It keeps this header, but it
**replaces the table**, including anything you already filled in.
